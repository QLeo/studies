# 공부서재

카테고리별 학습 페이지로 연결하는 정적 포털 샘플입니다. 루트의 `index.html`을 브라우저에서 열면 시작할 수 있습니다. 빌드나 패키지 설치는 필요 없습니다.

- 경제 · 금융: 기존 `economy/bacis/index.html`에 연결됩니다.
- 개발 · 기술, 인문 · 사회: 준비 중인 샘플 카테고리입니다.
- 검색과 상태 필터를 함께 사용할 수 있습니다.

새 카테고리는 `index.html`의 `.category` 항목을 복사하여 추가합니다. `data-search`에 검색어를, `data-status`에 `ready` 또는 `soon`을 설정하고 학습 페이지의 상대 경로를 링크에 넣으세요. 카테고리를 변경하면 화면 상단의 개수도 함께 수정하세요.

GitHub Pages에서 이 저장소의 루트를 게시하면 포털과 하위 학습 페이지를 함께 사용할 수 있습니다. 기존 경제 학습 자료의 폴더명 `bacis`는 연결 경로를 유지하기 위해 그대로 사용합니다.

디자인은 기존 경제노트의 네이비·블루·회색 토큰을 이어갑니다. 책등 일러스트와 번호가 붙은 서재 목록을 중심으로, 얇은 구분선과 여백을 사용합니다. 카테고리는 카드 격자 대신 행으로 배치하며 외부 이미지·폰트에 의존하지 않습니다.
